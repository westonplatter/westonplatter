I work full-time at [Masterpoint Consulting](https://github.com/masterpointio), helping clients plan, refine, and implement large-scale Terraform (Infrastructure as Code). I also enjoy taking on a range of data infrastructure and data engineering projects.

Outside of work, I'm enjoying the LLM renaissance and bringing a **beginner's mindset** to building patterns and agentic processes for software and data engineering. I learn the most by seeing what works and what fails in spectacular fashion. The projects below are where I'm actively letting myself and agentic dev teams experiment.

### Quant Finance

- **[ngv-trader](https://github.com/westonplatter/ngv-trader)** -- My personal system for running hedge-fund-style strategies across equities, commodities, and volatility markets.
- **[ngv_opx](https://github.com/westonplatter/ngv_opx)** -- A fast option pricing engine written in Rust, with bindings for Python and JavaScript. (Alpha)
- **[ib_insync_options](https://github.com/westonplatter/ib_insync_options)** -- Downloads option chain data from [IBKR](https://www.interactivebrokers.com/) using [ib_async](https://github.com/ib-api-reloaded/ib_async). Supports options on futures.
- **[ngv_reports_ibkr](https://github.com/westonplatter/ngv_reports_ibkr)** -- Custom reporting from [Interactive Brokers](https://www.interactivebrokers.com/) via the [Flex Query](https://www.interactivebrokers.com/docs/web-api/flex-web-service/client-portal-configuration/create-a-flex-query) API.
- **[fast_arrow](https://github.com/westonplatter/fast_arrow)** -- Python API client for Robinhood covering stocks, options, and portfolio management. (Archived)
